## 📌 아이템 및 장애물 설명
### [코인]
 - 큰 코인 : 많은 점수 획득
 - 작은 코인 : 점수 획득

### [포션]
 - 빨간 포션 : 플레이어 체력 증가
 - 파란 포션 : 플레이어 스테미나 증가
 - 초록 포션 : 플레이어 이동속도 증가

### [장애물]
- 폭탄 : 웨이브 마다 스폰되며 터지면 주변 장판 파괴<br/>
- 지뢰 : 닿으면 일정시간 이후 터지며 플레이어 체력 감소<br/>

## 📌 시스템 설명
### 💠 웨이브 시스템
각 레벨 마다 3단계의 웨이브를 가지고 있음<br/>
2, 3 웨이브에선 레벨에 맞게 장판 파괴 폭탄이 랜덤 생성됨<br/>

### 💠 레벨 시스템
총 3단계의 레벨로 구성되어 있음.
3레벨 완료 시 게임 오버되며 최종 점수를 알려줌

### 💠 리스폰 시스템
구역 밖으로 떨어지면 리스폰.
하늘에서 투명 발판에 리스폰 되며 일정시간 이후 발판이 사라져 다시 맵으로 복귀

### 💠 체력 및 스테미나
플레이어는 체력과 스테미나를 가지고 있음
#### [체력]
 - 폭탄과 낙하로 인해 감소하며 체력 포션으로 채울 수 있음
#### [스테미나]
 - 좌측 아래에 파란색으로 스테미나를 보여주고 있음
 - 스테미나가 있어야만 Sprint기능 사용 가능(Shift)
 - Sprint를 사용하지 않으면 자동으로 스태미나 회복
 - 파란 포션으로 스태미나 회복 가능

## 📌 UI
 - 실시간으로 남은 시간 출력
 - 스폰된 코인 개수 및 현재 획득한 코인 출력
 - 총 점수 출력
 - 현재 레벨 및 웨이브 출력
 - 웨이브 마다 폭탄 등장 문구 출력
 - 스테미나 출력
 - 초록 포션 획득 시 남은 시간 및 아이콘 출력
