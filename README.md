## 아이템 및 장애물 설명
### [코인]
 - 큰 코인 : 많은 점수 획득
 - 작은 코인 : 점수 획득

### [포션]
 - 빨간 포션 : 플레이어 체력 증가
 - 파란 포션 : 플레이어 스테미나 증가
 - 초록 포션 : 플레이어 이동속도 증가

### [장애물]
- 폭탄 : 웨이브 마다 스폰되며 터지면 주변 장판 파괴<br/>
- 지뢰 : 닿으면 일정시간 이후 터지며 플레이어 체력 감소<br/>

## 시스템 설명
### 웨이브 시스템
각 레벨 마다 3단계의 웨이브를 가지고 있음<br/>
2, 3 웨이브에선 레벨에 맞게 장판 파괴 폭탄이 랜덤 생성됨<br/>

### 레벨 시스템
총 3단계의 레벨로 구성되어 있음.
3레벨 완료 시 게임 오버되며 최종 점수를 알려줌

### 리스폰 시스템
구역 밖으로 떨어지면 리스폰.
하늘에서 투명 발판에 리스폰 되며 일정시간 이후 발판이 사라져 다시 맵으로 복귀
