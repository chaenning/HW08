- 📱 **언리얼 엔진 5.5.4**

- 🖥️ **Windows 플랫폼** (Windows 10.0.26100, Windows 7.0)
- 🌐 **.NET 8.0**

## 📌 기술 스택
### 💠 코어 시스템 설계
1. **게임 프레임워크 구조**
    - GameMode/GameState/GameInstance 활용한 게임 진행 관리
    - 컴포넌트 기반 설계로 높은 재사용성 확보
    - 이벤트 기반 시스템으로 느슨한 결합도 유지

2. **입력 및 상호작용**
    - Enhanced Input System을 활용한 키보드/마우스 입력 처리
    - 이벤트 기반의 UI 상호작용 시스템
    - Actor Component 기반의 모듈화된 시스템

3. **최적화 및 성능**
    - Timer 기반 파티클 시스템 관리
    - 동적 액터 스폰/제거 최적화
    - 효율적인 충돌 처리 시스템
    - DataTable을 활용한 데이터 관리

## 📌 게임 시스템
### 💠 레벨 시스템
- **3단계 레벨 구성**
    - 각 레벨별 3개의 웨이브 시스템
    - 웨이브 진행에 따른 난이도 상승
    - 최종 점수 기록 시스템

### 💠 아이템 및 장애물
 아이템 : DataTable 기반의 스폰 확률 관리
 
1. **코인 시스템**
    - 큰 코인: 높은 점수 보상
    - 작은 코인: 기본 점수 보상    

2. **포션 시스템**
    - 빨간 포션: 체력 회복
    - 파란 포션: 스테미나 회복
    - 초록 포션: 이동속도 증가
    - 전략적 사용이 필요한 밸런스 설계

3. **장애물 시스템**
    - 폭탄: 웨이브별 자동 생성, 장판 파괴 메커닉
    - 지뢰: 시간차 폭발, 체력 감소 효과
    - Timer 기반의 이벤트 처리

### 💠 캐릭터 시스템
1. **스탯 관리**
    - 체력 시스템: 장애물 및 낙하 데미지
    - 스테미나 시스템: Sprint 기능 연동
    - 자동 회복 메커닉

2. **리스폰 시스템**
    - 투명 발판 기반의 안전 리스폰
    - Timer 활용한 발판 소멸
    - 체력 페널티 시스템

## 📌 UI/UX 시스템
- **실시간 정보 표시**
    - 남은 시간
    - 코인 수집 현황
    - 점수 시스템
    - 레벨/웨이브 정보
    - 웨이브 알림 시스템
    - 스테미나 게이지
    - 버프 지속시간 표시

## 📌 기술적 특징
1. **모듈화된 설계**
    - 컴포넌트 기반 구조
    - 인터페이스 활용한 확장성 (Item)
    - 재사용 가능한 시스템 설계

2. **게임플레이 시스템**
    - 난이도 밸런싱 시스템
    - 리스크/리워드 메커닉
    - 전략적 플레이 유도

3. **최적화**
    - 효율적인 메모리 관리
    - 성능 최적화된 이벤트 처리
    - 동적 리소스 관리
